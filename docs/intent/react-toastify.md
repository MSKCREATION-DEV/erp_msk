# Intent — react-toastify (ERP MSK)

**Confirmé :** 2026-11-12

- **Outcome :** `react-toastify` = canal standard des feedbacks d’actions / soumissions
- **User :** tous les utilisateurs ERP
- **Why now :** uniformiser le feedback UI + règles strictes
- **Success :** toast success post-`redirect` (flash cookie) ; toast error **en plus** du message inline ; fondation branchée ; règle Cursor
- **Constraint :** charte MSK, App Router, pas de remplacement des erreurs inline
- **Out of scope :** toasts du centre de notifications in-app
