# Manuel — Organisation (structure MSK)

**Version** : 2026-10-10 · Phase 0 / socle  
**Public** : Direction, Admin

## À retenir

L’organisation décrit **qui est qui** dans MSK : pôles, postes, rattachements — distincte des **droits** (IAM).

- Un collaborateur peut figurer dans l’orga **et** avoir des groupes/packs différents.  
- Modifier l’orga ne change **pas** automatiquement les packs (sauf parcours d’invitation qui propose des groupes).

## Navigation

| Écran | Route | Permission typique |
|---|---|---|
| Hub organisation | `/organisation` | `org.view` |
| Collaborateurs / structure | selon menus livrés | `org.*` |

## Ce qu’engendre une action

| Action | Conséquence |
|---|---|
| Créer / rattacher un poste | Visibilité organigramme |
| Invitation user + groupes | Droits d’accès modules (pas l’inverse) |
