# 09 — RH cœur

Public : **Admin RH** · **Direction** (lecture / validations) · **Collaborateur** (Mon espace).  
Modules : `/rh` (admin) · `/espace` (self).

## Qui voit quoi

| Pack | Accès |
|---|---|
| `admin_rh` | Hub RH, collaborateurs, contrats, validation congés/absences/heures |
| `direction` | Accès RH lecture + validation congés |
| `collaborateur` | Mon espace : demander congé, déclarer absence, saisir heures |

Paie / INPS = **Phase 5** — voir [10-paie-inps.md](./10-paie-inps.md). Éligibilité types de contrat : Administration → Éligibilité contrats.

## Parcours clés

### 1. Fiche collaborateur

1. **RH → Collaborateurs → Nouveau**
2. Renseigner identité, type, solde congés ; lier un compte User optionnel
3. Consulter la fiche `/rh/collaborateurs/[id]`

### 2. Contrat

1. **RH → Contrats → Nouveau**
2. Lier un collaborateur, type (CDI/CDD/STAGE/PRESTA…), dates, salaire XOF optionnel
3. Activer le contrat (statut ACTIVE)

### 3. Congé (collab → RH)

1. Collaborateur : **Mon espace → Congés** → dates → Demander
2. RH : **RH → Congés** → Approuver / Refuser
3. Si congés payés approuvés : mouvement `CONSUMPTION` au ledger + solde décrémenté
4. Acquisition mensuelle automatique (+2,5 j / mois, prorata embauche) via cron `/api/cron/rh-leave-accrual`
5. Historique des mouvements visible sur `/espace/conges` ; régularisation RH (+/−) sur la fiche collaborateur

### 4. Absence

1. **Mon espace → Absences → Déclarer** (`/espace/absences/nouveau`) — motif + justificatif GED optionnel
2. RH : **RH → Absences** → Justifiée / Non justifiée (interface distincte)

### Types de congés (catalogue)

Voir `/rh/conges/types`. Types `MATERNITE` etc. seedés **inactifs** jusqu’à validation juridique MSK — ne pas inventer d’articles ni d’impacts paie.

### 5. Heures

1. **Mon espace → Heures** → calendrier théorique (horaire collectif 40 h) vs déclaré
2. Saisir la semaine + minutes/jour → Soumettre
3. RH : **RH → Heures** → Approuver / Refuser
4. Pas de badgeuse V1 — l’écart est informatif (référence contractuelle)

### 6. Règlement intérieur

Sur **Mon espace** : accuser / signer (statut SIGNED sur la fiche RH).  
Admin RH : générer le PDF « Règlement intérieur — accusé » depuis la fiche collab.

### 7. Documents PDF (charte MSK)

| Document | Où |
|---|---|
| Contrat (travail / stage / presta) | Fiche contrat → **Voir / Télécharger** si déjà généré, sinon Générer → GED `02_CONTRATS` |
| Attestation | Fiche collab → Documents RH → GED `05_DIPLOMES_ATTESTATIONS` |
| Règlement | Fiche collab → accusé PDF ; signature collab sur **Mon espace** |
| Solde de tout compte | Fiche collab → montant + Générer → GED `09_SORTIE` |
| Fiche de paie (indicative) | Fiche collab → GED `03_PAIE` (Phase 5 finalisera INPS) |
| Démo gabarits | Administration → Gabarits |

Si un PDF existe déjà : CTA **Voir / Télécharger** ; **Regénérer** en secondaire.

### 8. Mon espace (collaborateur)

Hub `/espace` : vue d’ensemble (identité cliquable, KPI, timeline). Subnav : Vue / Heures / Congés / Absences / Documents.

| Route | Contenu |
|---|---|
| `/espace` | Vue d’ensemble — identité → fiche ; alertes (ex. règlement à signer) |
| `/espace/profil` | Fiche personnelle (hors nav) — édition multi-champs + photo immédiate |
| `/rh/profil-demandes` | File RH — valider modifications perso |
| `/espace/documents` | Coffre unique (contrats, bulletins, règlement, paie…) |
| `/espace/conges` | Synthèse + calendrier + ledger ; création `/espace/conges/nouveau` |
| `/espace/absences` | Listing ; déclaration `/espace/absences/nouveau` |
| `/espace/heures` | Théorique vs déclaré ; saisie `/espace/heures/nouvelle-semaine` |
| `/rh/horaires` | Config horaires collectifs (séparé des feuilles) |
| `/rh/conges/types` | Catalogue types (réf. Mali — stubs à valider juriste) |
| Signature image | `/profil/signature` |
