# 09 — RH cœur

Public : **Admin RH** · **Direction** (lecture / validations) · **Collaborateur** (Mon espace).  
Modules : `/rh` (admin) · `/espace` (self).

## Qui voit quoi

| Pack | Accès |
|---|---|
| `admin_rh` | Hub RH, collaborateurs, contrats, validation congés/absences/heures |
| `direction` | Accès RH lecture + validation congés |
| `collaborateur` | Mon espace : demander congé, déclarer absence, saisir heures |

Paie / INPS = **Phase 5** — voir [10-paie-inps.md](./10-paie-inps.md). Éligibilité types de contrat : Administration → Éligibilité contrats.

## Parcours clés

### 1. Fiche collaborateur

1. **RH → Collaborateurs → Nouveau**
2. Renseigner identité, type, solde congés ; lier un compte User optionnel
3. Consulter la fiche `/rh/collaborateurs/[id]`

### 2. Contrat

1. **RH → Contrats → Nouveau**
2. Lier un collaborateur, type (CDI/CDD/STAGE/PRESTA…), dates, salaire XOF optionnel
3. Activer le contrat (statut ACTIVE)

### 3. Congé (collab → RH)

1. Collaborateur : **Mon espace → Congés** → dates → Demander
2. RH : **RH → Congés** → Approuver / Refuser
3. Si congés payés approuvés : solde décrémenté

### 4. Absence

1. **Mon espace → Absences** → déclarer
2. RH : **RH → Absences** → Justifiée / Non justifiée

### 5. Heures

1. **Mon espace → Heures** → semaine + minutes/jour → Soumettre
2. RH : **RH → Heures** → Approuver / Refuser

### 6. Règlement intérieur

Sur **Mon espace** : accuser / signer (statut SIGNED sur la fiche RH).  
Admin RH : générer le PDF « Règlement intérieur — accusé » depuis la fiche collab.

### 7. Documents PDF (charte MSK)

| Document | Où |
|---|---|
| Contrat (travail / stage / presta) | Fiche contrat → **Voir / Télécharger** si déjà généré, sinon Générer → GED `02_CONTRATS` |
| Attestation | Fiche collab → Documents RH → GED `05_DIPLOMES_ATTESTATIONS` |
| Règlement | Fiche collab → accusé PDF ; signature collab sur **Mon espace** |
| Solde de tout compte | Fiche collab → montant + Générer → GED `09_SORTIE` |
| Fiche de paie (indicative) | Fiche collab → GED `03_PAIE` (Phase 5 finalisera INPS) |
| Démo gabarits | Administration → Gabarits |

Si un PDF existe déjà : CTA **Voir / Télécharger** ; **Regénérer** en secondaire.

### 8. Mon espace (collaborateur)

Hub `/espace` : vue d’ensemble personnelle (KPI réels, alertes, activité récente, actions rapides).  
Sans ouvrir l’arborescence GED complète :

| Raccourci | Contenu |
|---|---|
| `/espace` | Hub — solde congés, demandes en cours, dernier bulletin, timeline |
| `/espace/profil` | Dossier perso (lecture) — demande de modification à venir |
| `/espace/contrats` | Timeline carrière (contrats + avenants + PDF + échéances) |
| `/espace/documents` | Docs RH liés (téléchargement) |
| `/espace/conges` | Demande + historique (validateur, notes) |
| `/espace/absences` | Déclaration + historique (qualification RH) |
| `/espace/heures` | Feuilles hebdomadaires |
| `/espace/bulletins` | Bulletins approuvés / payés |
| Règlement | Signer si PENDING ; Voir PDF si généré |
| Signature e-sign | Grisée sur le hub — upload image signature : `/profil/signature` |
