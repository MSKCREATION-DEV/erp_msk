# 09 — RH cœur

Public : **Admin RH** · **Direction** (lecture / validations) · **Collaborateur** (Mon espace).  
Modules : `/rh` (admin) · `/espace` (self).

## Qui voit quoi

| Pack | Accès |
|---|---|
| `admin_rh` | Hub RH, collaborateurs, contrats, validation congés/absences/heures |
| `direction` | Accès RH lecture + validation congés |
| `collaborateur` | Mon espace : demander congé, déclarer absence, saisir heures |

Paie / INPS = **Phase 5** (hors scope).

## Parcours clés

### 1. Fiche collaborateur

1. **RH → Collaborateurs → Nouveau**
2. Renseigner identité, type, solde congés ; lier un compte User optionnel
3. Consulter la fiche `/rh/collaborateurs/[id]`

### 2. Contrat

1. **RH → Contrats → Nouveau**
2. Lier un collaborateur, type (CDI/CDD/STAGE/PRESTA…), dates, salaire XOF optionnel
3. Activer le contrat (statut ACTIVE)

### 3. Congé (collab → RH)

1. Collaborateur : **Mon espace → Congés** → dates → Demander
2. RH : **RH → Congés** → Approuver / Refuser
3. Si congés payés approuvés : solde décrémenté

### 4. Absence

1. **Mon espace → Absences** → déclarer
2. RH : **RH → Absences** → Justifiée / Non justifiée

### 5. Heures

1. **Mon espace → Heures** → semaine + minutes/jour → Soumettre
2. RH : **RH → Heures** → Approuver / Refuser

### 6. Règlement intérieur

Sur **Mon espace** : accuser / signer (statut SIGNED sur la fiche RH).  
Admin RH : générer le PDF « Règlement intérieur — accusé » depuis la fiche collab.

### 7. Documents PDF (charte MSK)

| Document | Où |
|---|---|
| Contrat (travail / stage / presta) | Fiche contrat → **Générer PDF contrat** → GED `02_CONTRATS` |
| Attestation | Fiche collab → **Attestation** → GED `05_DIPLOMES_ATTESTATIONS` |
| Règlement | Fiche collab → **Règlement intérieur** → GED `06_REGLEMENT_INTERIEUR` |
| Solde de tout compte | Fiche collab → montant + **Solde** → GED `09_SORTIE` |
| Fiche de paie (indicative) | Fiche collab → **Fiche de paie** → GED `03_PAIE` (Phase 5 finalisera INPS) |
| Démo gabarits | Administration → Gabarits |
