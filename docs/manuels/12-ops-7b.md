# 12 — Ops Phase 7B (Achats, patrimoine, projets, anomalies)

Public : packs **Stock**, **Projets**, **Direction**.

## Achats (`/stocks/achats`)

1. Créer un achat (fournisseur + lignes, article stock optionnel)
2. Passer commande → **Réceptionner** → ENTREE stock auto + écriture **AC** brouillon (601 / 4011)
3. Lien vers la pièce comptable depuis la fiche

## Patrimoine (`/patrimoine`)

- Fiches biens (code, catégorie, valeur, assignation)
- Sortie d’actif (cession / réforme)

## Projets (`/projets`)

- Projet + budget ; dépenses avec seuil justificatif **25 000 XOF**
- Validation Direction / responsable : Approuver / Refuser / Rembourser

## Anomalies (`/ops/anomalies`)

- Tickets priorité / statut / assigné
- Critique ouvert > 48 h mis en avant sur la liste
